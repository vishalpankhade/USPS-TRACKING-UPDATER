# Privacy

USPS Bulk Tracker is designed to process tracking information locally in the user's Chrome browser.

- The extension does not require a paid tracking API or a hosted tracking database.
- Tracking numbers and results are stored in Chrome local storage for the extension's operation.
- USPS tracking requests go to the official USPS tracking website.
- Google Sheets data is accessed only when the user configures and uses the optional Google Apps Script bridge.
- The bridge is owned and deployed by the user.
- The project does not intentionally collect analytics, advertising identifiers, or a central database of tracking numbers.

Users should not publish customer/order information, private spreadsheet data, bridge secrets, or other confidential information in GitHub issues or screenshots.
