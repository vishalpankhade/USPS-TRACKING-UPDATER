One-time Google Apps Script setup

Use the deployed /exec URL in the extension. The /dev URL is for development/testing and is not the production URL to distribute with the extension. Deploy the script as a Web app and execute it as you. If your Workspace allows anonymous web apps, Anyone is the simplest option. If your Workspace only allows Anyone with Google account, click Open Apps Script Web App once in the same Chrome profile, sign in/authorize it if Google asks, then return and try again.

The bridge creates/reuses USPS Status and USPS Link columns and matches rows using a normalized tracking number, including numbers with spaces, hyphens or quotes.

Uses the official USPS tracking website. No USPS tracking API key is required.
