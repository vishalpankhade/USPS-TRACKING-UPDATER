# Installation from GitHub

## Chrome developer installation

1. Download the latest release ZIP from the GitHub Releases page.
2. Extract the ZIP.
3. Open Chrome and visit `chrome://extensions`.
4. Turn on **Developer mode**.
5. Click **Load unpacked**.
6. Select the extracted folder containing `manifest.json`.
7. Pin **USPS Bulk Tracker** from the extensions menu.

The extension is an unpacked developer installation. This is useful for personal/work use and for testing releases. A Chrome Web Store listing is recommended for general end users.

## Updating

Download the newest release ZIP, extract it to a new folder, then use **Reload** on the Chrome extensions page or load the new folder.

## Important

Do not upload your Google Apps Script secret, private spreadsheet data, or customer/order information to the repository.
