# Installation

## From a GitHub release

1. Download the latest extension ZIP from the repository release page.
2. Extract the ZIP.
3. Open `chrome://extensions`.
4. Enable **Developer mode**.
5. Click **Load unpacked**.
6. Select the extracted `extension` folder (the folder containing `manifest.json`).

## Updating

Remove/replace the old unpacked extension folder, then use **Load unpacked** again with the new `extension` folder.
